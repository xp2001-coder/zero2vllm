# 固定调度负载

[workloads.json](workloads.json)由[实验运行器](../../../../../scripts/experiments/lesson0204.py)读取。模型配置固定为 seed=7、词表 16、宽度 8、最大上下文 32；上下文大小也影响本参考模型的随机权重初始化，比较时请保持相同配置。

每个 case 包含 `name`、`description`、`limits` 和 `requests`。请求字段：

| 字段 | 约定 |
| --- | --- |
| `id` | 非空、全组唯一 |
| `arrival` | 非负整数；在该轮开始前提交；同轮按文件顺序 |
| `prompt` | 非空有效整数 token ID 列表 |
| `max_new_tokens` | 非负整数；零输出立即结束 |
| `eos_token_id` | 可选；EOS 计入输出并结束请求 |
| `cancel_at` | 可选；不早于到达的整数边界；在该轮计划生成前取消 |

输入先整组校验，再回放。无输出请求无需满足 P≤T；仍需满足词表和模型上下文限制。其他请求必须满足完整 prompt 可在一轮计算、最大输入长度可放入总预留容量。

六组负载对应长短混合、计算额度不足、FIFO 容量阻塞、稀疏到达、停止/取消和长 prefill 轮转。它们是为验证约束设计的教学输入，不代表线上流量分布。
