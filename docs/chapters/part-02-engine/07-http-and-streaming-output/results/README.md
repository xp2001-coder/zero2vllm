| 观察项 | 本次结果 |
| --- | --- |
| 普通流 | accepted、三项 token、done；输出 [12,3,8] |

| 输入与入口限制 | 400 / 415 / 422，以及 413 / 408 / 503 均符合预期 |

请求 ID 每次随机；断连前服务器额外推进的步数也可能随调度变化，不作为逐字复现条件。验收看事件顺序、完整重算对照、提前终止、同伴隔离与资源最终归还。
