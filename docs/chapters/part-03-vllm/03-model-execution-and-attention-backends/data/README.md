# 3.3 实验输入与源码清单

[返回实验](../lab.md)

- [requests.json](requests.json)：独立构造的一轮输入。A 的旧进度 2、本轮 3、块表 [8,3]；B 的旧进度 3、本轮 1、块表 [5]。默认执行顺序为 B、A，块长 4，保留块 0 不使用。不是上一节调度器的连续运行快照。
- [source-manifest.json](source-manifest.json)：固定官方仓库、tag、完整提交、15 个文件的 LF SHA-256、27 个函数及限定调用、2 类结构的字段。可以复用 3.1/3.2 的部分官方源码下载目录，但需要补齐本清单文件。

两份文件都不包含模型 checkpoint 或设备测量数据。变更默认输入后，需同步手算表、预期数组、图稿、测试与实际记录；日常探索优先使用短示例的执行顺序和填充参数。
