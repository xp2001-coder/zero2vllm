# 3.1 源码清单

[实验页](../lab.md) · [源码清单](source-manifest.json)

清单固定 vLLM v0.8.5 的完整提交、25 个文件的 SHA256、38 个函数的限定名与待核对调用表达式，以及 4 类消息结构的字段。

哈希前仅将 CRLF 转为 LF，允许 Git 在 Windows 上转换换行；任何其他文件修改仍会导致检查失败。源文件与上游 Apache-2.0 LICENSE 下载到忽略目录，不在课程中复制整份源码。

这是阅读约定，不是自动发现的全量调用图。`client-choice` 用于比较客户端形态；实际 AsyncLLM 路径以 `front-init` 为准。嵌套函数用完整词法作用域定位，避免同名方法误匹配。
